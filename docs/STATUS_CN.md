# 当前状态（2026-08-24）

## 一句话结论

13,767面、dHat=1.5 mm、slow solver、全程实体摩擦的版本可以完成三折；
第一、第二折四次抓取严格通过，第三折完成翻面和释放但持续抽滑约90 mm。

正式入口：

```bash
./scripts/run_demo.sh
```

## 已验证结果

- 980/980帧，无CUDA、TOI或NaN错误；
- 物理耗时1110.61秒，平均0.882 FPS；
- 左手两次、右手前两次抓取PASS；第三次右抓FAIL；
- 第二折层叠覆盖率77.23%，layering PASS；
- 第二折中央主体中位位移13.72 mm，但边缘p90为132.86 mm，motion FAIL；
- 第三折固定上片中位位移22.33 mm，最终覆盖率46.49%，motion PASS但余量小；
- 最终离桌高度中位21.65 mm、p90 49.66 mm；
- 10 mm网格局部叠层包络中位53.47 mm、p90 64.96 mm；
- 全程 `virtual_grasp=false`，没有隔空牵引。

## 参数消融

| 配置 | 结论 |
|---|---|
| dHat=2.0 mm | 稳定，但多层空气垫更明显，成品更厚 |
| dHat=1.5 mm | 当前稳定主线，相比旧2 mm结果薄约17--21% |
| dHat=1.0 mm slow | frame251发生`cudaMallocAsync`峰值分配失败 |
| dHat=1.0 mm fast | frame181触发约`-3.7e-13`的微负TOI断言 |
| soft virtual grasp | 能提高完成率，但会隔空牵引，已退出正式主线 |

dHat是接触激活距离，不是材料厚度。1.5→1.0 mm在同配置静置状态中让
最低层间位置降低约0.5 mm、中位高度降低约1.0 mm；完整成品还受落点、
滑移、摩擦锁定和沉降影响。

## 主要问题

1. 第三折真实夹住但持续抽滑，严格抓取指标不合格。
2. 第二折边缘区域拖动较大，当前stationary mask需要语义化改进。
3. 最终释放后没有额外沉降，局部叠层仍约53 mm。
4. dHat=1 mm同时存在CCD数值余量和显存工作集问题。
5. 尚未做多次重复运行。
6. Genesis依赖本地补丁，SIM1资产/轨迹不在本仓库。

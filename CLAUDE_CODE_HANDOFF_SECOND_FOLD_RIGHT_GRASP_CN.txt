## 1. 当前结论（请先看）

当前 Demo **不能视为三折已经成功**。最明确、最应优先修复的问题是：

> 第二折时，机器人右手虽然执行了闭合命令，但没有形成有效的布料夹持；右手随后独自抬升并远离布料。

这会产生连锁影响：

1. 第二折主要由左手单边拉动，衣服整体被向机器人方向拖移并发生扭转；
2. 第三折使用原轨迹的固定抓取位置，因此抓取点相对衣服发生偏移；
3. 第三折即使偶尔夹起，最终折叠形状也会堆叠、偏心，且释放后容易回缩。

先前曾根据成片视觉误判“第二折基本可用”，这个判断已经被关键帧诊断数据推翻。请优先解决第二折右手接触/夹持，不要先继续手调第三折坐标。

## 6. 最可能原因（按优先级）

### A. 右手闭合时几何位置不对

这是目前最可能的原因。frame 439 最近布料仍约 34 mm，而当前手指有效夹持区可能没有覆盖该布料。视觉上夹爪接近衣服，不等价于布料位于两个碰撞指面之间。

重点检查：

- frame 430、439、445 的两个手指 IPC 碰撞体，而不只是 Viewer 渲染网格；
- 布料是否处于 `right_link27` 与 `right_link28` 之间；
- TCP 定义 `TCP_LOCAL` 是否适合这个三角形夹爪；
- `right_link26` Viewer 刚体姿态与 IPC ABD 碰撞体姿态是否存在偏差。

### B. `--second-fold-right-approach-lift 0.08` 抬得过高或回落时机不对

当前右手 approach 修正会在靠近闭合帧时保留部分高度，再于 frame 455 前淡出。虽然设计目的是越过第一折折片，但它可能导致 frame 439 闭合时仍高于真正夹持区。

不要直接完全取消避障。建议把“高位横移”和“最后垂直下降”明确拆成两段：

1. frame 400--425：保持高位清障；
2. frame 425--439：在水平位置基本不变时垂直下降到布料；
3. frame 439：闭合；
4. frame 439--455：先竖直抬升，再进入水平运输。

### C. 闭合时机相对布料到位时间过早

目前闭合事件由官方 openness 轨迹决定。若经过 Genesis/IPC 适配后，布料形态和机械臂到位时序与 SIM1 不一致，frame 439 可能还没把布料送进指间。

建议支持一个仅用于第二折右手的闭合时间偏移，例如测试 `+5/+10/+15` 帧，并保持其他动作不变。

### D. 指面碰撞几何或压力不足

现有公共参数：

```text
finger_overclose=0.001
right_finger_overclose_extra=0.00025
finger_kp=1000
finger_kv=50
robot_friction=2.0
cloth_friction=1.0
exact_finger_collision=true
```

但在确认布料确实进入两指之间以前，不要优先继续增大摩擦或 overclose。没有几何包夹时，摩擦参数无法建立正常力。

## 7. 推荐的调试顺序

### 第一步：只跑到第二折，保存密集关键帧

建议从现有调试命令开始：

```bash
cd /home/happy1041/Workspace/Up3/genesis_ipc_shirt_demo

CONTACT_MESH_FACES=2500 ./run_three_folds_improved.sh \
  --frames 500 \
  --no-record \
  --debug-second-fold-dir /tmp/genesis_second_right_debug
```

目前 `--debug-second-fold-dir` 只保存一组离散帧。建议将第二折右手附近加密为：

```text
420, 425, 430, 435, 439, 442, 445, 450, 455, 465, 480
```

每帧至少保存：

- 所有 cloth vertices；
- `right_link26/27/28` 的 Genesis pose；
- 对应的 IPC ABD transform；
- 两指间距；
- 到每个指面/碰撞体的最近布料点；
- 位于两指夹持体积内的布料点 ID 与数量。

### 第二步：建立“有效夹持”自动判据

当前 `ContactGraspDiagnostics` 使用最近点 patch 跟踪，但 frame 439 的 `expected_tcp_distance` 已经很大，候选 patch 可能不代表真正指间布料。

建议为右手第二折新增判据：

1. 闭合后，在两指局部坐标系形成夹持 slab/楔形体积；
2. 统计该体积内 cloth vertices 数量；
3. 跟踪这些点在 frame 439--480 的位移；
4. 若 TCP 上升超过 50 mm，而这些点中位上升不足 25 mm，则判定失抓。

这样可以自动搜索轨迹参数，不必靠俯视视频猜测。

### 第三步：只搜索右手末段 approach，不动其他参数

建议依次测试：

1. 闭合前最终下降量：`0, 10, 20, 30 mm`；
2. 沿夹爪局部横向的小偏移：`-15, -10, -5, 0, +5, +10, +15 mm`；
3. 闭合延迟：`0, +5, +10, +15 frames`。

先用 2500 面、到 frame 480 的短测试，以右手 patch/TCP 同步程度为评分。找到能稳定夹起的组合后，再跑 frame 620 验证第二折落点，最后才跑第三折。

### 第四步：验证是否同时夹住短袖正面和背面

短袖 OBJ 是闭合双层表面。右手夹起后，需要判断抓到一层还是两层。可以利用 OBJ 拓扑/法向或初始顶点对应关系，在夹持体积内区分正面与背面，要求两个表面都有点随 TCP 抬升。

## 8. 当前已做但不要误当作右手修复的改动

### 布料质量调整

当前使用：

```text
cloth_rho=800 kg/m³
cloth_thickness=0.0002 m
areal_density=0.16 kg/m²
OBJ area≈0.72 m²
total mass≈0.115 kg
```

它能减轻单手拉扯时衣服整体滑动，但不能替代第二只手的真实夹持。

### 第二折 transport lift

`--second-fold-transport-lift 0.04` 将闭合后的轨迹改为先抬升再水平运输。它对左手有效；右手未夹住时，只是让空夹爪抬高。

### 第三折 placement depth

`--third-fold-placement-depth 0.03` 会在第三折末段将右手降低 30 mm，使折片在释放前接触下层衣服。这一改动能减轻空中释放回缩，但第三折初始状态仍受第二折失败污染。

## 9. 不建议重复的尝试

- 单纯把桌面摩擦提高到 `2.0`：整体拖动会减少，但折片会粘住并竖起/堆积；
- 只增加第二折 transport 抬升到 `80 mm`：没有解决右手包夹，并可能增加侧向漂移；
- 在第二折末段对双手统一加世界坐标 `+X` 放松：没有解决折片堆积或右手失抓；
- 直接继续调整第三折抓取位置：会把第二折造成的状态误差硬编码进第三折，不稳定且不泛化；
- 在确认布料进入两指之间前继续加大摩擦：缺少法向包夹时无效。

## 10. 完成标准

第二折右手修复至少应满足：

1. frame 439 附近确有布料顶点处于两指有效夹持体积；
2. frame 439--480 右手 TCP 抬升时，被夹 patch 的中位高度同步上升；
3. frame 480 的 `patch_tcp_distance` 保持在约 20 mm 内，而不是当前约 96 mm；
4. 右手 patch 同时包含短袖正面和背面两层；
5. 到 frame 583 以前不发生明显滑脱；
6. 第二折后未抓主体不再因左手单边受力剧烈向机器人方向移动；
7. 通过上述条件后，再检查第三折是否仍需位置修正。
